# Hogar-San-Anibal-Di-Francia

Sistema de software para la gestión de inventario del Hogar San Aníbal Di Francia, proyecto para el curso Computación en la Sociedad CCOMP8-1.

## Paso 1: Instalar los requisitos

- [Node.js](https://nodejs.org) 22 o 24 LTS (mínimo 20.19). Incluye npm, no hay que instalarlo aparte.

## Paso 2: Verificar la instalación

Abrir una terminal nueva y ejecutar:

```bash
node --version
npm --version
```

Los tres deben mostrar un número de versión.

## Paso 3: Descargar el proyecto

```bash
git clone https://github.com/4rlyzzz/Hogar-San-Anibal-Di-Francia.git
cd Hogar-San-Anibal-Di-Francia/frontend
```

## Paso 4: Instalar las dependencias

```bash
npm install
```

## Paso 5: Ejecutar el programa

```bash
npm run dev
```

Abrir http://localhost:5173 en el navegador.
